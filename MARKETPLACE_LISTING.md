## Short description

A full-stack starter for building an online doctor and medical appointment service, with a Next.js/TypeScript frontend and a companion Express API backed by MongoDB and Supabase integrations.

## Product description

Nobito is a full-stack web application starter for teams building a doctor discovery, clinic, and appointment-oriented service. The project combines a modern Next.js frontend with a Node.js/Express API and integrations for authentication and supporting services.

### Technology stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend API: Node.js, Express
- Database: MongoDB with Mongoose
- Authentication/integration: Supabase
- Additional integrations in the codebase: Upstash Redis rate limiting and OpenAI-powered support endpoint
